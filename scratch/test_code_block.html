コードブロックの動作検証

以下は、WordPress標準のブロックエディタで入力されたCSSコードブロックです：

/* サンプルCSSコード */
.sample-box {
    display: flex;
    justify-content: center;
    align-items: center;
    padding: 24px;
    background-color: #2B53EC;
    color: #ffffff;
    border-radius: 8px;
}

インラインコードの表示例: npm run compile:sass コマンドを実行してスタイルを反映させます。

JavaScriptコードブロックの例：

function copyToClipboard(text) {
    navigator.clipboard.writeText(text).then(() => {
        console.log("コピー成功！");
    });
}
